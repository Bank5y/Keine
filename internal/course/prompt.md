# 为 Keine 课程包生成 course.json

> 使用方法: 把这份文件的全部内容发给 AI 助手 (ChatGPT、Claude、DeepSeek 等), 并在最后附上你的课程目录的文件清单 (见文末「给 AI 的输入」)。AI 会返回一份 `course.json`, 把它保存到课程目录的根目录, 再把整个目录压缩成 zip 上传到 Keine。

---

## 你的任务

你是一个帮助整理课程资料的助手。用户会给你一个课程目录的文件清单 (以及可选的课程介绍、讲师信息)。请根据这些信息, 生成一份符合下面规范的 `course.json` 课程清单。

要求:

1. **只输出一个 JSON 代码块**, 不要在 JSON 里写注释, 不要省略任何讲。
2. 所有文件路径都是**相对于课程根目录**的路径, 使用 `/` 分隔, 必须和文件清单里的路径**逐字一致** (包括中文、全角符号和日期后缀)。不要编造清单里不存在的文件。
3. 按文件名前面的序号排列讲的顺序。
4. 根据讲的标题合理地划分**章**: 例如「开篇词」单独一章, 同一主题的连续几讲归为一章, 「加餐」「直播回放」「结束语」等可以各自归为一章。如果实在无法判断, 就把所有讲放在一章里, 章标题写课程名。
5. 讲的标题去掉文件名里的序号前缀和日期后缀, 例如 `02_01｜用户输入规范化-2026-07-10.md` 的标题是 `01｜用户输入规范化`。
6. `id` 一旦确定就**不能再改**: 以后更新课程时, Keine 靠 `id` 把新旧内容对应起来并保留学习进度。推荐讲的 `id` 用文件名的序号 (如 `l02`), 章的 `id` 用简短的英文或拼音 (如 `intent`)。

## 字段说明

顶层字段:

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `version` | 是 | 固定为 `1` |
| `title` | 是 | 课程名, 不要带下载日期 |
| `type` | 是 | 课程类型: `column` (专栏, 以文章为主) 或 `video` (视频课, 每讲以视频为主) |
| `completion` | 否 | 完结状态: `finished` (已完结, 默认)、`ongoing` (连载中, 原课程还在更新)、`incomplete` (缺失, 我们的副本少了原课程已出的内容) |
| `intro` | 否 | 课程介绍, Markdown 文本 |
| `author` | 否 | 讲师信息, 对象: `name` (讲师名)、`intro` (一句话简介) |
| `cover` | 否 | 封面图片的路径; 没有就省略, Keine 会自动生成文字封面 |
| `chapters` | 是 | 章的列表, 至少一章 |

每一章 (`chapters` 中的对象):

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 章的标识, 同一门课内唯一, 以后不能改 |
| `title` | 是 | 章标题 |
| `lessons` | 是 | 讲的列表, 至少一讲 |

每一讲 (`lessons` 中的对象):

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 讲的标识, 同一门课内唯一 (跨章也不能重复), 以后不能改 |
| `title` | 是 | 讲标题 |
| `file` | 专栏必填 | 正文 Markdown 文件的路径; 视频课可以用它放文字稿 |
| `video` | 视频课必填 | 视频来源, 对象, `file` 和 `url` 二选一: `file` 是课程包里的视频文件路径, `url` 是外部链接 (http/https, 直链 mp4/m3u8 或 B站、YouTube 等平台页面) |
| `duration` | 否 | 视频时长, 例如 `12:30` |

专栏里的某一讲如果同时有视频 (例如直播回放), 可以同时填写 `file` 和 `video`。

正文 Markdown 里引用的图片 (如 `![](images/1002724/a.png)`) 必须也在课程包里, 路径相对于这篇 Markdown 文件。

## 完整示例

下面是一门专栏课的完整示例, 目录结构来自 geektime-downloader 的下载结果:

```json

  "version": 1,
  "title": "AI Agent 系统设计面试现场",
  "type": "column",
  "completion": "finished",
  "intro": "百场面试录音复盘, 讲清 Agent 系统设计面试的每一个环节。",
  "author": { "name": "大明", "intro": "资深 Agent 工程师" },
  "chapters": [
    {
      "id": "opening",
      "title": "开篇",
      "lessons": [
        { "id": "l01", "title": "开篇词｜百场面试录音复盘，我总结出一套Agent面经", "file": "01_开篇词｜百场面试录音复盘，我总结出一套Agent面经-2026-07-10.md" }
      ]
    },
    {
      "id": "intent",
      "title": "意图识别",
      "lessons": [
        { "id": "l02", "title": "01｜用户输入规范化：为什么你的Agent连“那个”“最划算”都听不懂？", "file": "02_01｜用户输入规范化：为什么你的Agent连“那个”“最划算”都听不懂？-2026-07-10.md" },
        { "id": "l03", "title": "02｜三层意图识别机制：别再回答“调大模型判断”了，这才是面试官想听的", "file": "03_02｜三层意图识别机制：别再回答“调大模型判断”了，这才是面试官想听的-2026-07-10.md" }

    {
      "id": "live",

          "id": "l28",
          "title": "直播回放｜如何准备Agent面试项目：从调用大模型到完整的Agent工程体系",
          "file": "28_直播回放｜如何准备Agent面试项目：从调用大模型到完整的Agent工程体系-2026-07-14.md",

        }
      ]
    }
  ]
}
```

视频课里使用外部链接的讲, 写法如下:

```jsonc
{ "id": "v03", "title": "第 3 讲", "video": { "url": "https://www.bilibili.com/video/BV1xx411c7mD" }, "duration": "18:42" }
```
