# 课程下架或删除时冻结当时的文件目录，删除改为软删除

订阅者在课程下架或删除后，仍然可以阅读自己已学完或有标注的讲（保留讲）。实现方式：下架或删除那一刻课程正在使用的文件目录被冻结，既不随课程更新被删掉，也不会被覆盖；订阅者的保留讲固定读这份冻结的目录和当时的课程清单。删除课程改成软删除，课程库和上传者那边都看不到它了，但只要还有订阅者保留着它的讲，数据和冻结的文件就一直留着；没人保留时才真正清理。课程更新本来就是把新文件写进新目录再切换过去，所以冻结只是不再删除那个旧目录，不用另外复制一份。

## Considered Options

- 订阅者继续读课程当前的内容：下架后课程是上传者的私有课程，上传者之后的更新会改掉订阅者已学过的内容；删除之后则什么都不剩。
- 为每个订阅者单独复制保留讲（正文和图片）：语义最清楚，但存储随订阅者人数增长，复制本身也要处理图片等资源的引用。
- 删除时直接拒绝（有订阅者就不让删）：管理员没法处理违规内容。

## Consequences

- 课程的删除和文件清理要分开：删除只做标记，文件清理要等到没人再保留。
- 读一讲时要先判断这名用户是读当前内容，还是读他的冻结版本。
- 课程重新公开后，订阅者回到当前内容；冻结的那份没人用了就清理。
