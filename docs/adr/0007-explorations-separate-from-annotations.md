# 探索是独立的对象，不是标注的一种样式

探索（固定下来的一次分析）和标注都挂在专栏正文的一段文字上，都只有本人可见，看起来很像给标注多加一种样式。我们没有这样做，而是把探索做成独立的对象，只复用 ADR 0003 按原文片段加前后文的定位方式。探索挂着一份结构固定的探索文档（标题、简短介绍、概念阐述），以后还会挂上多分支的探索对话；它的内容来自 AI，生命周期也和笔记不同。笔记是用户自己写的一段文字，没有脱离标注单独存在的笔记。把探索塞进标注，会让标注的样式、笔记和筛选都要区分「这条其实是探索」。

## Considered Options

- 作为标注的第三种样式（横线、荧光笔之外再加「探索」）：可以复用存储、边栏和迁移的现成代码，但一条标注要么有笔记，要么有探索文档和对话，模型里到处都要分情况处理，笔记页的筛选和统计也会被混进来。

## Consequences

- 同一段文字可以同时有标注和探索，正文里两种样式叠加显示。
- 一段文字最多属于一个探索：选区和已有探索有重叠时，不能再发起分析。
- 课程更新后，探索也需要重新定位和迁移，不能自动沿用标注迁移的流程，要单独接入。
