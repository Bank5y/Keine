# 课程包必须带 course.json，不从文件名推断结构

导入课程包时，只认根目录的 `course.json`（课程清单）：课程信息、章与讲的分组、每讲对应的文件都以它为准，缺少清单就拒绝导入。我们评估过从 geektime-downloader 的 `NN_标题-日期.md` 文件名推断讲、甚至猜测章，但这种格式只是一个来源的约定，换一门课或换一个工具就会解析错，而且下载结果里本来就没有章的信息。为了降低写清单的门槛，系统提供可下载的提示词模板，用户交给 AI 生成清单。

## Consequences

- 导入只有一条路径：校验清单，再入库。
- 以后的 AI 能力（例如 Agent 自动拆分章节）接在「清单生成器」这个扩展点上：只负责生成清单草稿，用户确认后走同一条导入路径，不另开解析分支。
