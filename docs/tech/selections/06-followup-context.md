# 选型六：后续轮的上下文

> 所属：[Keine Explore Harness v1](../Keine_explore_harness_v1.md) · 附录 D
>
> 结论：**先作答。上下文只给读者已有的背景（课程信息、选区、首轮问答、祖先链历史），课程内容由模型按问题用工具检索。**

---

## 1. 问题

后续轮是读者在探索对话里的追问，可以发生在主节点，也可以发生在子节点、分支节点、发散节点。分支和发散节点本该走出本讲，甚至走出课程。

上下文要回答两个问题：课程内容以什么分量进入请求？模型怎样理解这些内容的身份？

需要面对的事实：

- **注入内容就是回答范围**：排在请求最前面、分量最重的内容，模型会把它当成回答的边界，只靠提示词抵消，效果不稳定；
- **首轮回复有示范作用**：首轮回复的口吻和结构会被后续轮模仿；
- **措辞沿祖先链累积**：上层回复里交代出处的说法原样进入下层上下文，节点越深越明显；
- **缓存要求前缀一致**：同一节点的各轮请求要共享尽量长的前缀。

## 2. 评估维度

| 维度 | 说明 |
| --- | --- |
| 回答范围 | 回答是否被框在本讲或课程里 |
| 信息可得性 | 模型需要课程内容时能否拿到 |
| 措辞 | 是否诱发交代信息出处的说法 |
| 成本 | 每一轮的输入体积和额外调用 |
| 前缀缓存 | 同一节点各轮请求的前缀能否复用 |

## 3. 候选方案

### 3.1 方案 A：先注入，后作答

```mermaid
flowchart LR
  S["课程信息 + 目录<br/>+ 选区 + 本讲全文"] --> R["带标签的首轮回复"] --> D["探索文档"] --> H["历史"] --> Q["提问"]
```

| 优势 | 劣势 |
| --- | --- |
| 模型手边信息最全，少用工具 | 课程成了回答范围，分支和发散节点也绕回本讲 |
| 实现直接，快照原样拼入 | 每一轮都带着整讲正文，输入体积大 |
| — | 文档和标签形式的首轮回复诱发交代出处的措辞 |

### 3.2 方案 B：作答前先按问题检索课程

```mermaid
flowchart LR
  Q["提问"] --> K["检索课程<br/>相关片段"] --> C["背景 + 片段 + 历史"] --> M["作答"]
```

| 优势 | 劣势 |
| --- | --- |
| 只带与问题相关的片段，体积小 | 回答依然由课程内容开头，范围问题没有解决 |
| — | 每一轮多一次检索，检索片段随问题变化，破坏前缀缓存 |

### 3.3 方案 C：先作答，课程按需检索（选定）

```mermaid
flowchart LR
  B["背景（读者已读）<br/>课程信息 + 选区"] --> F["首轮问答<br/>问句 + 分析正文"] --> H["历史"] --> Q["提问"] --> M["作答<br/>课程工具 · 网络工具"]
```

| 优势 | 劣势 |
| --- | --- |
| 课程只作背景，回答方向由提问决定 | 需要课程细节时要多一次工具调用 |
| 输入体积小，同一节点的请求逐轮延长，前缀可缓存 | 背景要从快照中取出，组装逻辑多一步 |
| 措辞约定集中在独立的回答风格模块里，可替换 | — |

## 4. 对比矩阵

| 维度 | A 先注入 | B 先检索 | **C 先作答** |
| --- | --- | --- | --- |
| 回答范围 | 框在本讲 | 框在检索片段 | **由提问决定** |
| 信息可得性 | 最全 | 按问题 | **按需检索** |
| 措辞 | 易交代出处 | 易交代出处 | **由回答风格约束** |
| 成本 | 每轮整讲正文 | 每轮多一次检索 | **最小** |
| 前缀缓存 | ✓ | ✗ | **✓** |

## 5. 结论与选择原因

选定：**方案 C，先作答**。

1. **范围问题来自注入本身。** A 和 B 都让课程内容排在回答之前，提示词只能削弱、不能消除这种分量。C 只给读者已有的背景，并标明是读者已读的内容。
2. **信息并没有丢。** 课程工具在每一轮都可用，模型需要哪一讲就读哪一讲；网络工具与之并列，适合走出课程的提问。
3. **首轮以问答出现。** 分析按选区粒度生成一句问句，答句是去掉标签的正文，不再以带格式的原始输出示范口吻。
4. **措辞约定独立成模块。** 回答风格带标识和版本，分析与后续轮共用，每一轮记录所用的版本，便于替换和对比。
5. **缓存成立。** 系统提示词、背景和首轮问答在同一探索里不变，同一节点的每一轮请求以上一轮请求加回复开头。
